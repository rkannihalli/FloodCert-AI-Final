📋 How Life-of-Loan Monitoring Works
When LOL monitoring is enabled for a determination, the system automatically checks FEMA FIRM map data daily for changes to: Flood Zone, NFIP Map Panel Number, Panel Effective Date, and NFIP Community Number (CID). If any value changes, an alert email is sent to the lender on file immediately. All alerts are logged and visible in the {% if current_user and current_user.is_admin %}Admin LOL Alerts tab.{% else %}Admin panel.{% endif %}
